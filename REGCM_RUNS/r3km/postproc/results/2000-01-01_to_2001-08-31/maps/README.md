**Author:** M. El Aabaribaoune (@um6p)

## Scientific Purpose
These diagnostics evaluate the RegCM-Toubkal simulation against observational and reanalysis products to assess:
- Mean climate behavior
- Seasonal cycle progression
- Spatial biases and structural model errors

## Reference Datasets
| Variable | Model | Reference | Model Resolution | Reference Resolution | Units |
|----------|-------|-----------|------------------|----------------------|-------|
| PR | RegCM-Toubkal (`*STS*.nc`) | MSWEP | ~3 km | 0.1° | mm day⁻¹ |
| TASMAX | RegCM-Toubkal (`*SRF*.nc`) | CPC | ~3 km | 0.5° | °C |
| TASMIN | RegCM-Toubkal (`*SRF*.nc`) | CPC | ~3 km | 0.5° | °C |

### Raw File Extraction
The RegCM-Toubkal data is loaded dynamically from the simulation's `archive_periods` directory for the given dates. Precipitation requires the STS (Surface Time Series) files for daily accumulations, while temperature extremes use the SRF (Surface) files.

## Processing Workflow
The evaluation strictly follows this sequence:
1. **Raw RegCM** (Extract variables and grid)
2. **Preprocessing** (Scale offsets, convert 3-hourly rates to accumulations)
3. **Temporal Aggregation** (Compute daily sums/means based on `is_rate`)
4. **Observation Harmonization** (Crop valid year, apply equivalent daily filtering)
5. **Regridding** (Model strictly mapped to Observation grid)
6. **Comparison** (Calculation of temporal means and biases on the common grid)
7. **Visualization** (Unified plotting applying strict Q1 publication styles)

## Bias Convention
Bias is strictly defined as:
**Bias = RegCM − Reference**
- Positive Bias = RegCM overestimation
- Negative Bias = RegCM underestimation

## Temporal Definitions
- **Arbitrary Periods**: Processing is now based on arbitrary `start_date` and `end_date` rather than a mandatory single year.
- **Period Mean**: For non-annual periods, the term "Period Mean" is used, representing the mean over all common valid daily fields inside the selected interval.
- **Seasons**: DJF (Dec-Jan-Feb), MAM (Mar-Apr-May), JJA (Jun-Jul-Aug), SON (Sep-Oct-Nov).
- **Seasonal Mean**: Mean of all COMPLETE meteorological-season occurrences fully contained in the selected interval. Partial seasons are excluded. DJF correctly crosses calendar years (e.g. Dec 2000, Jan 2001, Feb 2001 as one seasonal block).
- **Precipitation**: All precipitation maps (annual/period/seasonal) display **mean daily precipitation (mm day⁻¹)**.
- **Climatology vs Mean**: The term "Climatology" is strictly reserved for multi-year baseline averages. Single-year plots are titled "Annual Mean", while non-annual date ranges are titled "Period Mean".

## Scientific Colormaps & Conventions
Maps use fixed **discrete color classes** to ensure consistency across years and seasons:
- **PR (Precipitation):** `[0.0, 0.25, 0.5, 1.0, 2.0, 3.0, 5.0, 7.5, 10.0]` mm day⁻¹ (Sequential YlGnBu)
- **TASMIN (Min Temp):** `[-5, 0, 5, 10, 15, 20, 25, 30, 35]` °C (Diverging RdYlBu_r)
- **TASMAX (Max Temp):** `[5, 10, 15, 20, 25, 30, 35, 40, 45]` °C (Diverging RdYlBu_r)
- **PR Bias:** `[-4, -3, -2, -1, -0.5, 0, 0.5, 1, 2, 3, 4]` mm day⁻¹ (Diverging BrBG)
- **TAS Bias:** `[-8, -6, -4, -2, -1, 0, 1, 2, 4, 6, 8]` °C (Diverging RdBu_r)

*Bias is strictly defined as:* `Bias = RegCM - Observation`.

## Regridding Limitations
*Note on Precipitation*: Conservative regridding is scientifically preferable but currently fails because the RegCM `STS` files lack explicit cell boundaries (`xlat_bnds`). Bilinear is used as a fallback until bounding boxes are pre-calculated upstream.

## Figure Conventions
- Missing data (NaNs) are rendered in a neutral light-gray `#E0E0E0`.
- Bias panels enforce a symmetric zero-centered diverging colormap based on the maximum robust absolute error.
- All maps share a unified geographic extent strictly defining the Morocco study domain.

## Known Limitations
- Observational uncertainty in high Atlas precipitation can heavily influence apparent RegCM biases.
- Regridding limits (bilinear instead of conservative for PR).
- Single-year analyses (e.g., 2000) do not represent long-term climatology.
