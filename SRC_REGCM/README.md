# SRC_REGCM: Adapted RegCM Source Code

This directory contains the customized version of the RegCM (v4.5) source code adapted specifically for the Toubkal HPC architecture (`RegCM-Toubkal`).
It includes the environment setup file (`arch_RegCM4.5_Tbkl.env`) and a compilation script (`compile_regcm.sh`) to easily rebuild the executables. Binaries and compiled objects (`bin/`, `*.o`, `*.mod`) are generated during compilation and are intentionally ignored by Git.
